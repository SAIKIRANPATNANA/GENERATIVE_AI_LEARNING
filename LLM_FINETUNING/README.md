# LLM Fine-Tuning Learning

A focused learning track for understanding how modern language and multimodal models are adapted, aligned, compressed, and evaluated beyond basic prompting.

## What This Folder Covers

- Hugging Face fine-tuning workflows and dataset preparation
- Domain-specific pretraining and instruction fine-tuning
- LoRA and QLoRA parameter-efficient fine-tuning
- LLaMA Factory, Axolotl, and Unsloth practical workflows
- OpenAI and Gemini fine-tuning experiments
- Reward modeling, preference datasets, RLHF with PPO, DPO, ORPO, and GRPO
- Knowledge distillation and quantization concepts
- Embedding fine-tuning and multimodal / vision-model fine-tuning
- Practical notebooks, handwritten notes, PDFs, and small datasets used for learning

## Why It Matters

This track complements my RAG and LLM application work by showing the model-adaptation side of GenAI: when prompting is not enough, how data, adapters, preference signals, and evaluation choices can shape model behavior.

## Representative Modules

- `LLM Fine-Tuning-14` and `LLM Fine-Tuning-15`: domain and instruction fine-tuning
- `LLM Fine-Tuning-17`, `LLM Fine-Tuning-18`, and `LLM Fine-Tuning-19`: LLaMA Factory, Unsloth, and Axolotl
- `LLM Fine-Tuning-25`: LoRA and QLoRA
- `LLM Fine-Tuning-26`, `LLM Fine-Tuning-27`, `LLM Fine-Tuning-28`, and `LLM Fine-Tuning-29`: RLHF, GRPO, DPO, and ORPO
- `LLM Fine-Tuning-21`: Gemini fine-tuning
- `LLM Fine-Tuning-20`: OpenAI GPT fine-tuning
- `LLM Fine-Tuning-23` and `LLM Fine-Tuning-24`: multimodal and embedding fine-tuning

## Note

This is a learning-first folder. Some files are exploratory notebooks or notes rather than polished production projects, but together they show a broad practical foundation in LLM fine-tuning and alignment.
